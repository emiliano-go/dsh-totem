# Brief

**Question:** What are the best MCP tools and skills for coding — frontend design, unslopping UI, backend quality, and cybersecurity — as of 20/11/2026?

**Decision:** Choose a small, high-leverage MCP + skill stack for a DSH user who builds and ships web applications, and know which tools are safe to connect.

**Audience:** Emiliano; technically strong, wants production-ready recommendations, not a listicle.

**Scope**
- In: MCP servers (stdio/HTTP), Agent Skills (SKILL.md packages), and the security/selection criteria for both.
- In: tools usable with DSH or Claude Code today, with public docs/repos.
- Out: IDE-only extensions with no MCP/skill interface; paid enterprise suites with no public documentation; generic AI coding models.
- Out: exhaustive catalogues. This is a shortlist with reasons and tradeoffs.

**Success criteria**
- Every recommendation names what loop it closes (discover, change, verify, or secure).
- Every claim distinguishes official/maintained from community/popularity-only.
- Security advice is grounded in the MCP specification or a recognized security project, not vibes.
- The final stack is small enough to run without tool bloat.

**Selection criteria (used later)**
1. Official or clearly maintained; recent releases.
2. Narrow, typed tools; read-only default where possible.
3. Closes a real loop, not a demo.
4. Auth/scopes/secret handling are documented.
5. Token/tool-count cost is justified.
6. Works with DSH (stdio or HTTP MCP).

**Budget:** 25 searches, 15 pages read in full, 45 minutes, recursion depth 2.

**Evidence rule:** a load-bearing claim needs a primary source, or two independent secondary sources, plus an exact quote in the ledger.
